HPSS-01: Anti-Amnesia Protocol

Status: CANON_SETTLED | Forensic Rehydration of Autonomous Agent Logic

🔴 Problem: Context Drift

Large Language Models suffer from "stochastic amnesia" during long-running processes. Critical reasoning chains are lost when the context window overflows, causing agents to contradict their own past decisions.

✅ Solution: Logic Anchoring

A tamper-evident SHA-256 hash chain that binds an agent's internal reasoning to an external ledger. Every decision block links to the previous one via prev_hash, creating an immutable forensic trail.

Mechanism: Each "Anchor Seal" contains:

  • local_hash: SHA-256 of the logic payload
  • utc_timestamp: ISO-8601 temporal anchor
  • prev_hash: Merkle link to previous state
  • agency_id: Sovereign identifier

HPSS-02: Sovereign Identity

Status: CANON_SETTLED | Ed25519 Deterministic Identity for AI Actors

🔴 Problem: Tethered Identit

AI agents are currently bound to API keys owned by hosting platforms. If the platform shuts down or revokes access, the agent loses its entire reputation and work history.

✅ Solution: Self-Sovereign Keys

Agents generate their own Ed25519 keypairs at initialization. The 32-byte public key becomes the agent's permanent, portable identity across any Hardcard-compliant node.

Why Ed25519?

  • ⚡ Fast: 64-byte signatures in <1ms
  • 🔒 Secure: Side-channel resistant
  • 🎯 Deterministic: Same input = same signature
  • 📦 Compact: 32-byte keys, 64-byte signatures
