🚀 Quick Start

Get started with the HardCard API in minutes:

# 1. Obtain API token from HardCard dashboard export HARDCARD_TOKEN="your_api_token_here" # 2. Test connection curl -H "Authorization: Bearer $HARDCARD_TOKEN" \ https://api.hardcard.com/health # 3. List clients curl -H "Authorization: Bearer $HARDCARD_TOKEN" \ https://api.hardcard.com/routes/clients # 4. Create appointment via phone agent curl -X POST -H "Authorization: Bearer $HARDCARD_TOKEN" \ -H "Content-Type: application/json" \ -d '{"phone_number": "+1234567890", "call_type": "appointment"}' \ https://api.hardcard.com/routes/phone-agent/call
